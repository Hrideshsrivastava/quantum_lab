Classical Bits vs Qubits

A classical computer stores information in bits — each is either 0 or 1 at any given moment. A quantum computer uses qubits. The key difference isn't speed — it's the fundamental rules governing the physics of information.

Property Classical Bit Qubit
Possible values 0 or 1 (one at a time) α|0⟩ + β|1⟩ (superposition of both)
Can be copied? Yes — freely No — No-Cloning Theorem
On measurement Value unchanged State collapses to 0 or 1, probability from |α|², |β|²
Multi-qubit states 2ⁿ states, only one at a time Superposition over all 2ⁿ states simultaneously
Correlations Always local Can be entangled — non-local correlations

Qubit State Vectors

The state of a qubit is a unit vector in a 2D complex vector space (Hilbert space). We write it in bra-ket (Dirac) notation:

|ψ⟩ = α|0⟩ + β|1⟩

Where:

  • α, β are complex numbers (amplitudes)
  • |0⟩ = [1, 0]T and |1⟩ = [0, 1]T are the computational basis states
  • The normalisation condition must hold: |α|² + |β|² = 1
  • |α|² = probability of measuring 0, |β|² = probability of measuring 1
Why complex numbers? Complex amplitudes carry both a magnitude (probability weight) and a phase. The relative phase between |0⟩ and |1⟩ determines how quantum states interfere — constructively or destructively. This is the engine behind every quantum algorithm.

Superposition

A qubit in superposition doesn't "secretly" have a value — it genuinely occupies multiple states simultaneously until measured. The equal superposition state is:

|+⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

Measuring |+⟩ gives 0 or 1 each with 50% probability. But before measurement, the qubit responds to operations as if it is both 0 and 1 at once. An n-qubit system in superposition represents 2ⁿ basis states simultaneously.

Important: superposition ≠ randomness A random bit is unknown but has a definite value. A superposed qubit has no definite value. This is not a limitation — it's a computational resource: quantum algorithms use interference between the 2ⁿ branches to amplify correct answers and cancel wrong ones.

The Bloch Sphere

Every pure qubit state corresponds to exactly one point on the surface of the Bloch sphere. The geometric representation makes quantum gate effects intuitive:

  • North pole: |0⟩ (prob. 0 = 1)
  • South pole: |1⟩ (prob. 1 = 1)
  • Equator: equal superposition (50/50)

The state vector is parameterised by two angles:

|ψ⟩ = cos(θ/2)|0⟩ + eiφsin(θ/2)|1⟩

The Bloch vector (x,y,z) is derived from the state: x = 2Re(α*β̄), y = 2Im(α*β̄), z = |α|²−|β|²

Quantum Measurement

Measuring a qubit in state |ψ⟩ = α|0⟩ + β|1⟩ in the computational basis gives:

Outcome Probability State after measurement
0 |α|² Collapses irreversibly to |0⟩
1 |β|² Collapses irreversibly to |1⟩
The Measurement Problem This collapse is irreversible — you cannot "undo" a measurement. This is why quantum algorithms must be carefully designed: you only measure at the end, after all interference has shaped the probability distribution to peak at the correct answer.

Quantum Gates

Quantum gates are unitary matrices applied to state vectors. Unitary means U†U = I — gates are reversible and preserve the norm (total probability stays at 1). Unlike classical gates, most single-qubit gates have no classical equivalent.

X
[ 0 1 ] [ 1 0 ]
NOT gate: |0⟩↔|1⟩. π rotation about X-axis.
Y
[ 0 -i ] [ i 0 ]
Flip + phase: π rotation about Y-axis.
Z
[ 1 0 ] [ 0 -1 ]
Phase flip. |+⟩↔|−⟩. π rotation about Z-axis.
H
1/√2·[ 1 1 ] [ 1 -1 ]
Hadamard: creates superposition |0⟩→|+⟩, |1⟩→|−⟩.
S
[ 1 0 ] [ 0 e^iπ/2 ]
Phase gate: π/2 rotation about Z-axis.
T
[ 1 0 ] [ 0 e^iπ/4 ]
T-gate: π/4 rotation about Z-axis.
Key Property: Reversibility Every quantum gate U has an inverse U† (conjugate transpose). This means every computation is reversible — no information is ever lost. Classical logic gates like AND are irreversible (you can't recover the inputs from the output), which is why quantum computing requires fundamentally different circuit designs.

Entanglement

When two qubits interact (e.g., via a CNOT gate), they can become entangled — their states can no longer be described independently. The simplest entangled state (Bell state):

|Φ⁺⟩ = (1/√2)(|00⟩ + |11⟩)

This is not a product state — there's no way to write it as |A⟩ ⊗ |B⟩. Measuring the first qubit instantly determines the second — regardless of distance. This non-local correlation is what Einstein called "spooky action at a distance."

Why entanglement matters for computing Entanglement allows n qubits to represent and manipulate correlations across all 2ⁿ basis states in parallel. Grover's algorithm uses it to amplify the correct answer; Shor's algorithm uses it to find periodicity exponentially faster; QKD uses it to guarantee information-theoretically secure communication.
