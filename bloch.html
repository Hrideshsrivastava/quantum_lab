Gate effects on the Bloch sphere

Xπ rotation about X-axis. |0⟩ ↔ |1⟩ (quantum NOT)
Yπ rotation about Y-axis. Adds i phase to |1⟩
Zπ rotation about Z-axis. |+⟩ ↔ |−⟩
Hπ/2 about (X+Z)/√2. |0⟩ → |+⟩, |1⟩ → |−⟩
Sπ/2 rotation about Z-axis. Phase gate.
Tπ/4 rotation about Z-axis. T-gate.
💡 How it works: State |ψ⟩ = α|0⟩ + β|1⟩ is stored as complex amplitudes. Each gate compounds a 2×2 complex unitary U via Strassen's algorithm (7 complex ×, not 8). Repeated gate sequences are served from a DP memoization cache — zero recomputation. Bloch vector: (x,y,z) = (2Re(αβ̄), 2Im(αβ̄), |α|²−|β|²).
