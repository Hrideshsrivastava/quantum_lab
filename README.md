# Modern Physics Virtual Lab  

**Interactive Mach–Zehnder Interferometer Simulation for Structural Health Monitoring**

This project was developed for the DEI x Virtual Labs Hackathon 2026. It is a web-based interactive platform designed to help students understand key concepts of Modern Physics, particularly Mach–Zehnder Interferometry, and its real-world engineering applications.

---

## Problem Statement

Mach–Zehnder Interferometers play a crucial role in optical sensing and structural health monitoring. However:

- Concepts are often taught using static diagrams and equations  
- Limited connection to real-world applications  
- Difficult for students to visualize interference and phase changes  
- Lack of interactive platforms linking theory to engineering decisions  

As a result, students understand theoretical concepts but struggle with practical relevance.

---

## Solution and Innovation

This project introduces an interactive virtual lab that:

- Visually demonstrates interferometry concepts  
- Connects optical phase changes with physical deformation  
- Helps users understand how measurements influence engineering decisions  

The platform bridges the gap between theoretical physics and real-world applications.

---

## Key Features

### Dual-Mode Learning Platform
- **Learning Mode:** Interactive conceptual understanding  
- **Engineering Mode:** Application-based simulation  

### Interactive Simulation
- Visualizes beam splitting, phase shift, and interference  
- Demonstrates how small physical changes affect results  

### Application-Based Demonstrations
- Bridge structural health monitoring  
- Aircraft structural safety simulation  

### Concept-to-Decision Visualization
- Converts optical data into meaningful indicators  
- Displays structural status (Safe / Inspection / Critical)

## How It Works (Process Flow)

1. User accesses the web-based platform  
2. Selects mode:
   - Learning Mode (conceptual understanding)  
   - Engineering Mode (application-based simulation)  
3. Adjusts parameters such as load, temperature, altitude, and turbulence  
4. System computes deformation, strain, and optical phase change  
5. Output is displayed through:
   - Interference patterns  
   - Structural health indicators
